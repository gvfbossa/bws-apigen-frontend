Requirements & Limitations

Designed for modern Spring applications. Make sure your project meets the requirements below.

Requirements

  • ✔ Java 17 or higher
  • ✔ Spring Boot project
  • ✔ Standard @Entity class Annotation
  • ✔ Standard @Id Annotation
  • ✔ Getters and Setters for fields (Lombok @Getter and @Setter supported)
  • ✔ Maven or Gradle project structure

Current limitations

  • • Complex inheritance strategies may require manual adjustments
  • • Custom repository logic is not generated
  • • Advanced validation annotations may not be fully mapped
  • • Existing files are not overwritten automatically
  • • Machine-based licensing is used to protect commercial usage

We are continuously improving support for more advanced use cases.
